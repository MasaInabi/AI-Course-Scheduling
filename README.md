# AI Course Scheduling

An AI-based course scheduling system designed to generate suitable academic schedules while considering different scheduling constraints.

## About the Project

This project was developed as part of the COMP338 course. It focuses on solving the course scheduling problem using Artificial Intelligence optimization techniques.

The system organizes courses, instructors, rooms, student groups, and time slots to generate an optimized schedule while reducing scheduling conflicts.

## AI Algorithms

The project implements:

- Genetic Algorithm
- Hill Climbing

## Main Features

- Course scheduling and organization
- Instructor and room assignment
- Time slot management
- Student group management
- Schedule optimization
- Conflict reduction

## Technologies

- Java
- JavaFX
- Maven
- FXML
- CSS

## Project Structure

The project includes classes for courses, instructors, rooms, time slots, student groups, populations, selection, mutation, and AI optimization algorithms.
